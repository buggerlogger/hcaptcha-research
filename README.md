# Notes

One note per puzzle. The pictures sit in the same folder as the note. This page is only the list.

[Piece drag](piece_drag/README.md). Two pieces, one hole. Either the hole is a darkened copy of the piece, or the piece's outline is what fits the hole.

[Letter fits](letter_fits/README.md). Read the letter in your hand, then find the green copy of that same letter on the board.

[Outline match](outline_match/README.md). Fill each thin outline and see which one has the same silhouette as the piece.

[Ring complete](ring_complete/README.md). The icons sit on a circle. The empty spot is the one gap that is about twice as wide as the others.

[Both shapes](xboth/README.md). The X has to land where the two outlines overlap.

[Screw](screw/README.md). The empty joint is thick wood near the middle of the planks, where the plank edges meet at several angles.

[Shape grid](shape_grid/README.md). Find the empty cell, then take the piece that matches the other shapes in that column.

[Vial](vial/README.md). Scale each vial to each hole and keep the pair whose outlines agree.

[Scale](scale/README.md). The higher pan is the light one. If the beam is level, the animal goes on the pan that does not already show it.

[Tile boards](label_binary/README.md). A 3 by 3 of pictures, and a question. Each wording only uses a small list of objects, so the yes and no objects can be written down.

[Area select](area_select/README.md). Click a spot on a still picture: letters behind a ribbed glass, arrows around a circle, a broken pattern, rings, and a few cases I have only seen as video.

[Video](video/README.md). The same kind of click, but the page is a short clip. Turning, the bee, a category, the odd one out, the animal that lays eggs.
